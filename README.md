NotesApp is a simple Android application that allows users to create, read and delete notes. The app uses the ROOM persistence library for local database storage, ensuring that user data is safely stored on the device.

Features:
Create new notes
Delete notes
View a list of all saved notes
Notes saved locally using ROOM Database
Tech Stack:
Language: Kotlin
Architecture: MVVM (Model-View-ViewModel)
Database: ROOM Database
UI: Jetpack Compose
Dependency Injection: Hilt
