NotesApp is a simple Android application that allows users to create, read and delete notes.
The app uses the ROOM persistence library for local database storage, ensuring that user data is safely stored on the device.

Features:
1. Create new notes
2. Delete notes
3. View a list of all saved notes
4. Notes saved locally using ROOM Database

Tech Stack:
1. Language: Kotlin
2. Architecture: MVVM (Model-View-ViewModel)
3. Database: ROOM Database
4. UI: Jetpack Compose
5. Dependency Injection: Hilt
6. Coroutines: For background tasks!
